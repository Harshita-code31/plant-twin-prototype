# Plant Twin Prototype (Anubhav)

Workforce-competency prototype for oil & gas plants: rare-event drills on a 3D plant twin, an Experience Vault of veteran decisions, mentor debriefs and a competency map.

**Live:** [plant-twin-prototype.vercel.app/web/](https://plant-twin-prototype.vercel.app/web/) (training app) · [/web/copilot/](https://plant-twin-prototype.vercel.app/web/copilot/) (SOP copilot)

- `web/`: the browser prototype (start here; see `web/README.md`).
- `web/copilot/` and `api/`: the bilingual SOP copilot and its backend (see `web/copilot/README.md`).
- `Assets/`, `ProjectSettings/`, `Packages/`: the AbhyasAR Unity app this project started from.
- `supabase/`, `dashboard/`: AbhyasAR backend migrations and admin dashboard.
